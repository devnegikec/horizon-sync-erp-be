## 🚀 Quick Start

### 1. Import Collection
```
Postman → File → Import → Select JSON file → Import
```

### 2. Set Variables
```
Environment dropdown → Set:
- base_url = http://localhost:8001/api/v1
- access_token = YOUR_JWT_TOKEN
- organization_id = YOUR_ORG_UUID
```

### 3. Test Upload
```
Bulk Import Operations → 1. Upload CSV File for Import → Send
```

### 4. Check Status
```
Bulk Import Operations → 2. Get Import Job Status → Send
```

## 🔑 Key Features

### Authentication
- Bearer token authentication
- Auto-populated from environment variable
- Ready for JWT tokens

### Job Tracking
- Status monitoring (PENDING → PROCESSING → COMPLETED)
- Error details with row numbers
- Statistics (total, successful, failed)

### Filters & Options
- Item type filter
- Status filter
- Search by item code/name
- Column selection
- Pagination support

### File Support
- CSV format
- XLSX format
- JSON format
- 50MB max file size
- 10,000 rows max

- Save export job ID to `export_job_id` variable
- Enable chaining requests

## 📝 Example Requests

### Import Example
```bash
POST /bulk-import/upload
Body: form-data with CSV file
Response: Job ID + Status
```

### Export Example
```bash
POST /bulk-export
Body: {
  "file_format": "csv",
  "filters": {"item_type": "Stock", "status": "Active"}
}
Response: Job ID + Export URL
```

## 🔍 Status Codes

- **202 Accepted** - Job created successfully
- **200 OK** - Request successful
- **400 Bad Request** - Invalid data
- **401 Unauthorized** - Missing/invalid token
- **404 Not Found** - Job not found
