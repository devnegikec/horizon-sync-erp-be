## 🚀 QUICK START (5 Minutes)

### Step 1: Import Collection
```
1. Open Postman
2. Click File → Import
3. Select: Horizon_Sync_Bulk_Import_Export.postman_collection.json
4. Click Import
```

### Step 2: Configure Environment
```
1. Click Environment dropdown (gear icon)
2. Create new or select existing
3. Add variables:
   base_url = http://localhost:8001
   access_token = <your JWT token>
   organization_id = <your org UUID>
```

### Step 3: Upload Sample File
```
1. Go to: Bulk Import Operations → 1. Upload CSV File
2. Select: sample_import_data.csv
3. Click Send
4. Note the returned job_id
```

### Step 4: Check Status
```
1. Go to: Bulk Import Operations → 2. Get Import Job Status
2. Click Send
3. Watch status change from PENDING to COMPLETED
```

### Step 5: Export Data
```
1. Go to: Bulk Export Operations → 1. Create Export Job
2. Click Send
3. Use the returned job_id to download file
```

✅ **You're done!** The API is working.

## 🆘 NEED HELP?

### Common Issues & Solutions

**"Invalid token"**
- Get new JWT from identity-service
- Paste into access_token variable

**"Port 8001 not accessible"**  
- Start core-service: `docker-compose up core-service`
- Wait for container to be ready

**"Database tables not found"**
- Run: `docker exec horizon_postgres psql -U horizon_user -d core_db < core-service/scripts/create_bulk_import_export_tables.sql`

**"File upload fails"**
- Verify file format (CSV, XLSX, JSON)
- Check file size (max 50MB)
- Check rows (max 10,000)
